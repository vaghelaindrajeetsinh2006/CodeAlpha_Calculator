# 📖 About Project

The **CodeAlpha Calculator** is a modern and responsive web application built using **HTML, CSS, and JavaScript**.

This project was created to strengthen JavaScript fundamentals by implementing arithmetic operations, DOM manipulation, event handling, responsive layouts, and interactive user interface components.

The calculator provides a smooth user experience with support for keyboard shortcuts and calculation history while maintaining a clean and modern design.
